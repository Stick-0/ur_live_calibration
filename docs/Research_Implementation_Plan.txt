# 두 로봇 캘리브레이션 이후 협업 제어 구현 계획

## 1. 구현 목표와 범위

현재 구현된 두 로봇의 캘리브레이션 기능을 바탕으로, **각 정반이 독립적으로 움직이더라도 두 로봇 말단의 상대 위치와 방향을 유지하고, 그 상태에서 협업 작업을 진행하는 기능**을 구현한다.

외부 카메라 한 대로 두 로봇을 동시에 관측하며, 두 로봇팔이 서로 가리는 상황은 고려하지 않는다. 기존 포즈 추정기는 네트워크, voting, PnP를 포함해 수정하지 않고 하나의 포즈 센서로 사용한다. 기존 방법이 제공하는 카메라 좌표계 기준 로봇 포즈를 후속 처리와 제어의 입력으로 활용한다. Main_Manuscript

추가할 부분은 **포즈 센서와 로봇 제어기 사이에 들어가는 상태처리·목표 생성 모듈**이다. 전체 구조는 다음과 같다.

**기존 캘리브레이션·포즈 추정 → 상대 상태 처리 → 베이스 이동 보상 및 작업 목표 생성 → 기존 로봇 제어기**

## 2. 협업에 사용할 상대 상태 관리

먼저 두 로봇의 포즈 출력을 주기적으로 받아, 협업 제어에서 사용할 상대 베이스 상태를 관리한다.

각 로봇의 카메라 기준 베이스 포즈를 \( {}^{C}T_{B_1} \), \( {}^{C}T_{B_2} \)라고 하면, 두 로봇 사이의 상대변환은 다음과 같이 계산한다.

\[
{}^{B_1}T_{B_2}
=
\left({}^{C}T_{B_1}\right)^{-1}
{}^{C}T_{B_2}
\]

이 상대변환과 각 로봇의 관절각으로 계산한 말단 자세를 이용하면, 두 말단이 서로 어디에 있고 어떤 방향을 향하는지 계산할 수 있다.

다만 제어에 사용할 때는 **포즈가 측정된 시각과 결과를 전달받은 시각을 구분**한다. 같은 영상에서 얻은 두 로봇의 포즈는 처리 완료 시각이 달라도 같은 촬영 시각의 측정값으로 취급한다. 서로 다른 시각의 결과를 사용해야 한다면, 두 상태를 공통 시각으로 맞춘 후 상대변환을 계산한다.

초기 구현에서는 측정값을 직접 사용하는 방식부터 동작시키고, 이후 일반적인 필터와 단기 운동 예측을 추가한다. 필터는 정지 상태에서의 불필요한 출력 흔들림을 줄이고, 예측은 측정 이후 제어 시점까지 발생했을 베이스 이동을 보상하는 데 사용한다. 위치뿐 아니라 회전 변화도 함께 처리한다.

이 모듈은 제어기에 **현재 시점으로 보정한 상대변환, 상대 이동속도, 마지막 유효 측정 이후 경과시간**을 제공하도록 구성한다. 별도의 신뢰도 출력이 없어도 시작할 수 있으며, 기존 시스템에서 제공하는 품질 정보가 있다면 보조적으로 활용한다.

예측은 짧은 측정 공백을 보완하는 용도로 제한한다. 갑작스러운 정반 이동을 미리 정확하게 예측하거나, 출력만으로 실제 이동과 측정 오류를 항상 구분한다고 가정하지 않는다.

## 3. 첫 제어 기능: 두 말단의 상대 자세 유지

첫 단계에서는 물체 인계나 접촉 작업보다, **두 말단 사이에 정해진 상대 위치와 방향을 유지하는 비접촉 추종 기능**을 구현한다.

초기 구성은 A를 기준 로봇, B를 추종 로봇으로 두는 방식으로 시작한다. A는 자신의 베이스 기준으로 정지하거나 미리 정한 간단한 동작을 수행하고, B는 A 말단에 대해 지정한 상대 자세를 유지하도록 움직인다.

예를 들어 A 말단에서 일정 거리 떨어진 위치를 B의 목표로 정한다. A 또는 B의 정반이 움직이면 상대 베이스 변환이 달라지므로, B의 베이스 좌표계에서 표현한 목표 자세를 계속 갱신한다. 이때 A의 말단 자세는 관절각으로 계산하여, A의 팔 운동과 정반 이동을 모두 목표 생성에 반영한다.

**유지해야 할 상대 자세는 작업 시작 시 정해 두고, 매 순간 측정되는 현재 상대 자세로 다시 설정하지 않는다.** 현재 측정값은 목표를 바꾸는 기준이 아니라, 정해진 목표와의 오차를 계산하는 데 사용한다.

이 단계의 목표는 다음 동작을 확인하는 것이다.

> **정반이 움직이지 않을 때는 불필요하게 흔들리지 않고, 어느 한쪽 또는 양쪽 정반이 움직이면 팔이 이를 보상하여 두 말단의 상대 관계를 유지한다.**

처음에는 B가 보상을 담당하는 구조로 구현 범위를 좁힌다. 두 팔이 보상 동작을 나누어 수행하는 방식은 기본 기능을 검증한 이후의 확장으로 둔다.

## 4. 다음 제어 기능: 이동 보상과 작업 진행의 분리

상대 자세 유지가 동작하면, 고정된 상대 목표를 **시간에 따라 진행하는 상대 작업 경로**로 확장한다. 예를 들어 B가 A의 말단 주변에서 일정한 경로를 따라 이동하거나, A가 들고 있는 물체의 인계 위치로 접근하도록 한다.

이때 명령을 생성하는 과정에서 다음 두 목적을 구분한다.

**베이스 이동 보상은 정반 이동으로 인해 발생하는 상대 관계의 변화를 상쇄하는 운동**이다. **작업 진행은 미리 정한 상대 경로를 따라 앞으로 나아가는 운동**이다. 여기에 현재 상대 오차를 줄이는 피드백 보정을 함께 적용한다.

정반이 움직이면 상대 이동속도를 이용해 목표 자세가 어떻게 변할지 예측하고, 그 변화에 대응하는 보상 운동을 생성한다. 동시에 원래 작업 경로의 진행량을 계산하여 최종 목표에 반영한다.

핵심은 **정반 이동이 커졌을 때 작업 진행만 늦추고, 필요한 이동 보상은 유지할 수 있도록 하는 것**이다.

예를 들어 B가 A의 물체를 향해 접근하던 중 정반 이동이 빨라지면, 접근 경로의 진행속도를 낮춘다. 이때 접근을 늦추더라도 현재 작업 단계에서 요구하는 상대 관계를 유지하기 위한 보상은 계속한다. 반대로 정반 이동이 작아지고 운동 여유가 회복되면 작업 진행속도를 다시 높인다.

이를 위해 작업 경로의 진행률을 별도로 관리한다. **진행률을 멈추는 것은 상대 작업 경로에서 더 나아가지 않는다는 의미이지, 로봇 관절을 모두 정지한다는 의미는 아니다.** 정반이 움직이는 동안에는 동일한 작업 단계에 머무르기 위해서도 팔의 보상 운동이 필요할 수 있다.

## 5. 작업 진행속도와 중단 조건 관리

작업 진행속도는 현재 베이스 이동, 상대 추종 오차, 로봇의 운동 한계를 기준으로 조절한다.

베이스 이동을 보상하고도 여유가 있으며 상대 오차가 허용 범위 안에 있으면 정상 속도로 작업을 진행한다. 보상에 필요한 운동이 커지거나 상대 오차가 증가하면 진행속도를 낮춘다. 이 판단에는 관절 속도·가속도 제한, 목표 자세의 도달 가능성, 작업공간과 충돌 여유를 포함한다.

단순히 계산된 명령을 제한값에서 잘라 보내는 대신, **현재 조건에서 보상과 작업 진행을 함께 실행할 수 있는지 먼저 확인**하도록 구성한다. 보상만 수행해도 운동 한계를 초과하는 경우에는 작업 진행속도를 줄이는 것으로 해결할 수 없으므로 중단 조건으로 처리한다.

측정이 장시간 갱신되지 않거나 유효하지 않은 출력이 지속되는 경우에도 작업을 계속하지 않는다. 정상 추종 중 운동 여유가 부족한 경우와, 측정 자체를 신뢰할 수 없는 경우를 구분해야 한다. 전자는 작업 진행을 늦추면서 보상할 수 있지만, 후자는 보상 명령의 근거도 불확실한 상태이기 때문이다.

정반은 비구동이므로 로봇팔의 정지만으로 정반 이동까지 멈추는 것은 아니다. 따라서 실험에서는 **제어 중단 처리와 별도로 정반의 외부 이동을 멈추는 절차**를 마련한다.

## 6. 구현 순서와 검증

구현은 각 기능의 효과를 분리해서 확인할 수 있도록 단계적으로 진행한다.

| 단계 | 구현 내용 | 확인할 사항 |
|---|---|---|
| 1단계 | 캘리브레이션 출력을 이용한 상대 자세 유지 | 정반이 정지한 상태에서 두 말단의 상대 목표를 유지하는가? |
| 2단계 | 정반 이동에 따른 목표 갱신 | 한쪽 또는 양쪽 정반이 저속으로 움직일 때 상대 관계를 유지하는가? |
| 3단계 | 필터·시간 정합·단기 예측 추가 | 출력 흔들림과 지연의 영향을 줄이는가? |
| 4단계 | 상대 작업 경로 및 진행률 관리 | 이동 보상과 작업 진행을 동시에 수행하는가? |
| 5단계 | 운동 여유에 따른 감속·중단 처리 | 한계에 가까워질 때 작업 진행을 조절하고, 실행 불가능한 상태를 구분하는가? |

실험에서는 **직접 좌표변환만 사용하는 방법**, **필터와 예측을 추가한 방법**, **이동 보상과 작업 진행을 분리해 관리하는 방법**을 비교한다. 기존 포즈 추정기와 저수준 로봇 제어기는 동일하게 유지한다.

기록할 항목은 포즈 측정값과 타임스탬프, 관절 상태, 생성한 목표, 상대 추종 오차, 작업 진행률, 중단 여부이다. 성능은 상대 말단의 실제 위치·회전 오차와 작업 완료시간을 함께 평가하며, 제어에 사용한 추정값으로 계산한 오차와 독립적인 기준으로 측정한 실제 오차를 구분한다. 작업을 더 느리게 진행한 효과만으로 개선된 것은 아닌지도 확인한다.

**최종적으로 구현할 것은 ‘움직인 좌표를 다시 계산하는 기능’에 더해, 측정값을 현재 시점의 상대 상태로 정리하고, 그 상태에서 베이스 이동을 보상하면서 협업 작업의 진행속도를 관리하는 모듈이다.**
